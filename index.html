05 · Physical research

Build less. Measure more. Prove the loop.

The project stays Class-10 feasible by keeping the physical scope narrow and repeatable, while letting the computational layer scale.

Research timeline

1 · Explore

Analyse the survey, map local waste streams and define the scientific hypothesis.

2 · Baseline

Measure reference fuel behaviour under controlled conditions.

3 · DOE

Use a structured design of experiments instead of random formulation guessing.

4 · Combustion tensor

Collect synchronized temperature, mass and calibrated/validated emission measurements.

5 · Learn

Fit models, quantify uncertainty and identify sensitive variables.

6 · Optimise

Generate Pareto sets and select the next experiments using active learning.

7 · Close the loop

Quantify recoverable heat/residue value and compare linear versus circular optimisation.

8 · Validate

Physically test unseen AI-selected formulations and report error honestly.

06 · Signature experiment

Make the circular hypothesis falsifiable.

The flagship result should compare two competing optimization philosophies using physical validation.

Optimizer A

Combustion-only

xA = argmax Ufuel(E, PM, CO, duration, stability, cost)

Find the formulation that looks best if the downstream loop is ignored.

Optimizer B

Cycle-aware

xB = argmax [ Ufuel + λQrecovered + μVdownstream + νGnext − ρRisk ]

Find the formulation/process point that maximises value across the entire defined system.

Signature test: If xA and xB differ reproducibly, and the circular objective produces measurable system-level gains under the defined boundary conditions, the project has demonstrated why single-stage optimisation can be insufficient for circular energy engineering.

09 · Novelty discipline

What is new — and what is not.

A strong national-level project is not the one with the boldest novelty claim. It is the one that knows exactly where prior art ends and its experiment begins.

Already established individually

Tea-waste valorisation, rice-husk energy, biomass briquettes, AI optimisation, ash valorisation, waste-heat drying, biomass supply-chain optimisation and industrial symbiosis all have prior art.

Potentially distinctive combination

Community-weighted + experimentally validated + time-resolved + uncertainty-aware + circularity-aware + sequential optimisation of a locally calibrated biomass-energy loop.

Preferred novelty language: “The literature contains many established components, but this project experimentally investigates whether cross-stage, community-weighted, uncertainty-aware optimisation changes the selected operating point when downstream heat/material/regeneration value is included.”

Final research statement

Does a locally calibrated biomass system become measurably better when its optimisation target expands from combustion performance to whole-cycle resource performance?

That is the question CYCLE-X should spend its experimental effort answering.
